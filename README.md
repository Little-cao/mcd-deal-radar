# 麦当劳全天候助手 · mcd-all-weather-assistant

> 一句话：**你订阅什么，就帮你盯着什么——一出新品、一降价、一发券、一有新活动，就发邮件通知你；
> 还能按你订阅的范围自动领券，以及定时点餐（到点帮你把单下好、把麦当劳 App 付款链接发给你）。**

「想吃巨无霸但不知道啥时候划算？」「想看新品什么时候上？」「想等咖啡券？」
——**想订阅什么都可以**，不限套餐。

用户只要说一句「帮我订阅 X」，之后按**用户设定的频率**（默认每天 12:00 / 24:00，
也可自行指定「早上 8 点」「每 3 小时」等）由**宿主智能体平台的定时任务**
（WorkBuddy、Hermes 或任何具备定时任务能力的平台）唤醒智能体，
**直接调用麦当劳 MCP 工具**拉取菜单、优惠券与活动日历，
发现变化就整理成一封邮件发到用户邮箱。

还支持**定时点餐**：按你设定的**周期**（工作日 / 每天 / 指定星期几 / 每月某日 / 一次性）
到点自动选好固定套餐、生成订单，**每次下单前自动查遍所有可用券、比价取最优**，
把**付款入口（麦当劳 App 链接）**推给用户，**由用户在自己的麦当劳 App 内付款**（绝不自动扣款）。
外送场景若没有收货地址，会**先让你填写地址才会下单**。

本项目为 **麦当劳程序员节创意开发大赛** 参赛作品。

## ✨ 设计要点

- **面向小白，全程带做**：假设用户什么都不懂——skill 会**手把手引导**完成
  「申请 Token → 配置 MCP → 建立订阅与定时任务」，用户只需照着做。
- **纯 Skill，无需脚本**：取数全部通过麦当劳 MCP 工具完成，智能体直接调用。
- **平台无关**：不绑定特定平台——凡「能连麦当劳 MCP + 有定时任务能力」的智能体平台均可运行，如 WorkBuddy、Hermes 等。
- **订阅由定时任务自带**：每条订阅 = 一个平台定时任务，天然持久，无需额外存储。
- **频率由用户决定**：默认每天 12:00 / 24:00，可随时改成任何时间或间隔。
- **定时点餐**：按用户设定的周期（工作日/每天/指定星期/每月某日/一次性）到点自动下好单，**下单前自动比价选最省的券**，把麦当劳 App 付款链接推给用户，**绝不代付**。
- **外送地址硬门槛**：外送下单必须有收货地址；没有就先请你填写，**绝不臆造地址下单**。
- **可被其他技能调用**：识别到「订阅/查询麦当劳优惠」的意图即可路由到本 skill。
- **只推变化**：没有新变化就不发邮件，不打扰用户。
- **可自动领券**：在你的订阅范围内一出现可领券，就顺手领进券包（**默认关闭，需你明确开启**）。

## 🚀 使用方式

### 你什么都不用准备，跟着它做就行

本 skill 由智能体驱动，**首次使用时会自动带你完成配置**：

```text
你：我想让它帮我盯麦当劳的优惠

智能体（自动检测到还没接通）：
  「得先让麦当劳官方给咱们一把『钥匙』，有了它我才能帮你查菜单和优惠。
   很简单，照着点几下，1 分钟就好：
   ① 打开 https://open.mcd.cn/mcp/doc
   ② 点右上角『登录』，手机号收个验证码登进去
   ③ 右上角点『控制台』→『激活』→ 同意一下协议
   ④ 看到一大串字母数字，点『复制』发给我就行～」

你：（照着做，把钥匙发来）

智能体：默默帮你配好 → 一试能查到 → 「开通好啦！🎉」
        接着问「你想让我帮你盯着啥？多久看一次你说了算」

你：盯巨无霸套餐，有新品或降价就发 me@qq.com，每天中午提醒我

智能体：搞定！以后每天中午帮你看一眼，有新动静就发邮件告诉你 ✅
```

之后你什么都不用管，有新动静它才会发邮件。

> 手动配置（进阶）：若你想自己配，也可参考下方说明。

### 手动配置（可选，进阶用户）

本 skill 需要宿主平台具备两项能力：**① 能连接麦当劳 MCP Server；② 具备定时任务能力**。
满足这两点的平台（WorkBuddy、Hermes 等）均可运行。以 WorkBuddy 为例：

1. **申请 MCP Token**：前往麦当劳 MCP 官方文档
   <https://open.mcd.cn/mcp/doc> → 登录（手机号验证）→ 点右上角「控制台」→「激活」→
   同意服务协议 → 一键复制 Token（**每个用户需自行申请**）；
2. 在平台的连接器设置中填入 MCP 配置（见项目根目录 `mcp-config.example.json`），
   把 `YOUR_MCP_TOKEN` / `${MCD_MCP_TOKEN}` 替换为你自己的 Token；
3. 启用 `mcd-mcp`。

> ⚠️ Token 无法由本 skill 代为申请；每个 Token 每分钟限 600 次请求，请妥善保管。
> 若你选择让智能体代配，Token 仅用于当次配置、不落库。

### 订阅

直接在对话里说，例如：

> 「帮我订阅巨无霸套餐，有新品或降价就发我邮箱 me@qq.com」

智能体会解析出订阅要素、**向你确认邮箱**，然后创建一条定时任务
（默认每天 12:00 / 24:00）。

### 自定义检查频率

频率由你说了算，订阅时说一句即可：

| 你说 | 创建的任务频率 |
| --- | --- |
| （不说，默认） | 每天 12:00、24:00 |
| 「每天一次」 | 每天 12:00 |
| 「早上 8 点提醒我」 | 每天 08:00 |
| 「只在晚上 8 点」 | 每天 20:00 |
| 「每 3 小时看一次」 | 每 3 小时 |
| 「工作日提醒」 | 周一至周五 12:00 |

订阅后也**随时可以改**：「改成每天一次」「以后晚上 8 点提醒我」「先停掉」。

### 订阅 + 自动领券（可选）

如果你不想每天手动去领券，可以让它**自动帮你领**——在你订阅的范围内一出现可领券，
就顺手领进你的券包，并发邮件告诉你领了哪些：

> 「帮我盯着咖啡的券，**有券自动领了**，发我邮箱 me@qq.com」

> 🔐 **默认关闭，需你明确开启**：领券会真实改变你的账户券包（属于"写操作"），
> 所以只有你说了「自动帮我领」它才会开；你随时可以说「以后别自动领了」关掉。
>
> 📌 **说明**：麦当劳的领券接口是「**一键领取全部可用券**」，无法只领订阅范围内的那一张。
> 所以它只在**你的订阅范围内出现可领券时**才去领，并在通知里**如实列出实际领到的券**。

### 定时点餐

除了「提醒优惠」，还能让它在你设定的周期**到点自动帮你把单下好**：

> 「**工作日**每天中午 12 点帮我点一份巨无霸套餐，外送到公司」
> 「**每天**早上 8 点帮我下个大杯咖啡，我到店自取」
> 「**每周一、三、五**中午帮我订个沙拉，送到公司」
> 「**就明天**中午 12 点，帮我点一份巨无霸套餐，外送到家」

**周期与时间由你说了算，但必须你说出口**——不说就不会默认设，会先问清你：

| 你说 | 触发的周期 |
| --- | --- |
| 「工作日」 | 周一至周五 |
| 「每天」 | 每天 |
| 「每周一三五」 | 周一、周三、周五 |
| 「每周末」 | 周六、周日 |
| 「每月 1 号」 | 每月 1 日 |
| 「就明天」/「仅 10 月 15 日」 | 一次性，执行一次后自动结束 |

到点后它会：确认命中周期 → 查最新菜单确认套餐在售 →
**查遍所有可用券（账户券 + 活动券 + 门店券）逐张比价、挑最省的那张** →
生成订单 → **把麦当劳 App 付款链接发到你邮箱**，你点开后在**麦当劳 App 里**付款。

> 🏷️ **永远帮你挑最省的券**：不是"有券就用"，而是把所有能用的券都算一遍，
> 取实际到手价最低的方案（面额大的券不一定最划算）。
>
> 📍 **外送必须有地址**：如果外送但账户里没有收货地址，它会**先让你填写地址**，
> 填好才会下单——绝不猜测或使用过时地址。
>
> 📱 **付款链接就是打开麦当劳 App 的链接**：点开会**唤起麦当劳 App**，
> 你在 App 内完成付款，**不需要在陌生网页里输入任何支付信息**。
>
> 🔒 **绝不自动扣款**：它只生成订单并给你 App 付款入口，**付款永远由你本人在 App 里确认**。
> 若你没付款，订单到期自动取消，不会重复催单。

智能体直接调用 MCP 工具取数并回答。

## 🧠 工作原理

```text
（首次使用）智能体检测到未配置 → 引导用户申请 Token → 代配 MCP → 验证 ✅
      │
      ▼
用户对话「订阅 X + 想要的频率」
      │
      ▼
智能体解析意图 → 确认邮箱与频率 → 创建平台定时任务（默认 12:00 / 24:00）
                                        │
                          （按用户设定频率触发，唤醒智能体）
                                        ▼
                     智能体调用麦当劳 MCP 工具取数
              query-meals / available-coupons / query-my-coupons
              / query-store-coupons / campaign-calendar / calculate-price / now-time-info
                                        │
                                        ▼
                     与上次结果比对 → 只保留【新增或变化】
                                        │
                          有新变化 ──▶ 整理摘要 ──▶ 发邮件到用户邮箱
                          无新变化 ──▶ 静默结束
```

**为什么不用自建脚本？** 因为宿主平台已通过连接器接入了麦当劳 MCP，
智能体可直接调用工具；自建脚本反而要重复实现 MCP 调用、管理 Token 与存储，
在 skill 场景下是多余的。详见 `docs/proactive-push.md`。

## ❓ 常见问题

**Q：我完全不懂技术，能用吗？**
A：能。这个 skill 就是为小白设计的——你只要说「我想盯麦当劳的优惠」，
它会一步步带你申请 Token、帮你配好 MCP，再问你想订阅什么。全程跟着做即可。

**Q：为什么默认检查两次，而不是实时？**
A：麦当劳 MCP 只有拉取能力，没有 webhook 推送；且优惠/活动按天更新。
默认 12:00 覆盖午市、24:00 覆盖夜间上新。不过频率**完全由你决定**——
想一天一次、早上 8 点、或每 3 小时都可以，订阅时说一声即可。

**Q：定时点餐会自动帮我付钱吗？**
A：**不会，永远不会。** 它只帮你把订单下好、把麦当劳 App 的付款链接发给你，
你点开在 **App 里**完成付款。你没付款的话订单会自动过期，它也不会重复催你。

**Q：点餐的周期可以随便设吗？**
A：可以。**每天、指定星期几、每月某日、甚至只点一次（明天）**都支持，
而且**不管什么周期，下单流程完全一样**——都查券比价、外送都校验地址、都绝不代付。
注意：**周期和下单时间必须你亲口指定**，你不说，助手不会替你默认，免得天天下单没人付款。

**Q：点餐会帮我用优惠券吗？**
A：会，而且是**每次都查、比价取最优**。下单前它会把账户券、活动券、门店券全部查一遍，
逐张算出到手价，选**实际支付最低**的那张（不是面额最大的）。
如果暂时没有可用券，就按原价下单，不会卡住。

**Q：外送但我没有收货地址怎么办？**
A：它会**先让你填写**收货地址（联系人 + 手机号 + 详细地址），存好后才会下单。
**地址缺失时绝不下单**——为的是避免送错、送丢。你也可以改用「到店取餐」。

**Q：在操作上，订阅检查、自动领券、定时点餐这三件事会互相打架吗？**
A：不会。自动领券是**搭在订阅检查同一趟**里做的（不额外建任务），
定时点餐是**独立的任务**；三者各用各的任务，互不干扰。

**Q：自动领券会不会把我账户里的东西弄乱？**
A：不会乱扣款——**领券不涉及任何支付**，只是把免费的券放进你的券包。
但它**默认是关的**，必须你明确同意才开；而且只在你订阅范围内出现可领券时才触发。

**Q：会自动帮我付钱吗？**
A：**不会，永远不会。** 领券是免费的；点餐也只做到「生成订单 + 给麦当劳 App 付款链接」，
付款永远由你**在自己的麦当劳 App 里**确认。

**Q：会被 MCP 限流吗？**
A：官方限制 600 次/分钟。一天两次检查、每次几条订阅，调用量极低，无需担心。

**Q：Token 安全吗？**
A：若让智能体代配，Token 仅用于当次配置、不写入任何文件、不落库；
长期由宿主平台的连接器统一管理，本 skill 不接触、不存储任何凭证
（见 `CONTEST_DECLARATION.md`）。
